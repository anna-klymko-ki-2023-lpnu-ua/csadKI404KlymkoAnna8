## Загальний опис проєкту

Проєкт присвячений створенню та автоматизації AI-агента для збірки й
тестування Python-додатку. Агент `build-engineer` керує ініціалізацією
проєкту, підготовкою віртуального середовища, запуском тестів і налаштуванням
кросплатформного CI.

## Запуск агента

1. Відкрийте каталог проєкту у середовищі **VS Code**.
2. Відкрийте панель **Copilot Chat**.
3. Оберіть кастомного агента **build-engineer**.
4. Виконайте базову команду `/init` для запуску повного циклу оркестрації.

## Доступні команди агента

| Команда | Призначення |
|---|---|
| `/git-init` | Перевірка Git-репозиторію та налаштування `.gitignore`. |
| `/create-project` | Створення базової структури Python-проєкту. |
| `/create-build` | Підготовка залежностей, тестів і скриптів збірки. |
| `/create-actions` | Створення та перевірка workflow GitHub Actions. |
| `/check` | Read-only аудит структури, тестів, CI та безпеки. |
| `/init` | Послідовний запуск повного циклу оркестрації. |
